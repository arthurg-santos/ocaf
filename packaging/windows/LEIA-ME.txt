OCAF 0.3.0 — Windows x86_64
================================

OCAF (Onood's Compressed Audio File) é um codec de áudio lossless.
O PCM decodificado é bit-exato: nada é arredondado ou descartado.

Conteúdo deste pacote
--------------------
  ocaf.exe        programa portátil, não precisa instalar
  LEIA-ME.txt     este arquivo
  LICENSE.txt     licença MIT
  SHA256SUMS.txt  checksum do ocaf.exe
  BUILD.txt       versão, alvo e commit de origem

Requisitos
----------
  Windows 10 ou 11, 64 bits.
  Não é necessário instalar Rust, MinGW ou qualquer runtime extra.

Aviso do Windows
----------------
  O executável não tem assinatura digital. Se o SmartScreen aparecer:
    1. Clique em "Mais informações".
    2. Clique em "Executar assim mesmo".
  Só execute arquivos recebidos de alguém em quem você confia.

Teste rápido
------------
Abra o Prompt de Comando ou PowerShell na pasta deste arquivo:

  ocaf.exe --version

  ocaf.exe encode musica.wav musica.ocaf
  ocaf.exe info musica.ocaf
  ocaf.exe verify musica.ocaf
  ocaf.exe decode musica.ocaf restaurada.wav
  ocaf.exe play musica.ocaf

Se o caminho tiver espaços, use aspas:

  ocaf.exe encode "C:\Minha Música\musica.wav" "C:\Minha Música\musica.ocaf"

O OCAF lê WAV nativamente (PCM 16/24/32 bits ou float 32/64 bits).
Para MP3, FLAC, AAC/M4A, Ogg, Opus, WMA, AIFF e vídeos, instale o
FFmpeg (ffmpeg.exe e ffprobe.exe) e deixe os dois no PATH:

  winget install Gyan.FFmpeg
  ou: choco install ffmpeg -y

Depois abra um terminal novo e use, por exemplo:

  ocaf.exe encode musica.flac musica.ocaf
  ocaf.exe encode musica.mp3 musica.ocaf
  ocaf.exe encode musica.mp3 musica-s16.ocaf --pcm-format s16

O OCAF guarda o PCM decodificado, não o arquivo comprimido original.
FLAC, ALAC e AIFF mantêm o PCM exato. Para fontes com perda (MP3, AAC,
Ogg, Opus, WMA), o padrão é o float 32 bits do decodificador, que é
bit-exato em relação a essa decodificação, mas pode ficar bem maior
que o original. Use --pcm-format s16 para um arquivo menor; essa
conversão tem perda em relação ao float. As tags do arquivo original
não são copiadas automaticamente; use --title, --artist, --album etc.

Comandos úteis
--------------
  ocaf.exe encode entrada.wav saida.ocaf
  ocaf.exe encode entrada.flac saida.ocaf
  ocaf.exe encode entrada.mp3 saida.ocaf --pcm-format s16
  ocaf.exe decode saida.ocaf restaurada.wav
  ocaf.exe play saida.ocaf
  ocaf.exe play saida.ocaf --player "C:\Program Files\mpv\mpv.exe"
  ocaf.exe info saida.ocaf
  ocaf.exe verify saida.ocaf
  ocaf.exe compare entrada.wav saida.ocaf
  ocaf.exe benchmark entrada.wav --iterations 5

Use --force para sobrescrever um arquivo que já existe.

Observações
-----------
  - O áudio decodificado é idêntico ao original; o cabeçalho WAV é
    regravado, então o arquivo WAV inteiro pode não ser byte-a-byte igual.
  - O codificador é single-thread e ainda é mais lento que codecs maduros.
  - Float64 de mantissa completa é o caso de pior compressão, mas continua
    bit-exato.
  - O comando play usa ffplay, mpv ou vlc se estiverem instalados; caso
    contrário usa o player do PowerShell, que só toca WAV PCM inteiro.
  - O play decodifica e verifica o arquivo inteiro antes de começar o som.
  - Para formatos diferentes de WAV, o ffmpeg.exe e o ffprobe.exe precisam
    estar no PATH. Eles não vêm dentro deste zip.
  - Esta é uma versão de teste 0.3.0, sem auditoria de segurança.

Ao reportar um problema, envie:
  - a saída de `ocaf.exe --version`;
  - o comando completo que falhou;
  - a mensagem de erro;
  - se possível, um WAV pequeno que reproduza o problema.
